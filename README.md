# Gerenciador de Tarefas (To-Do List CLI)

Projeto prático desenvolvido para o trabalho de **Gerenciamento de Configuração de Software (GCS)**, simulando um ambiente de desenvolvimento colaborativo com vários DEVs utilizando o Git e o GitHub.

## Equipe e Papéis
* **Guilherme** – Gestor de Configuração (Configuration Manager)
* **Gustavo** – Desenvolvedor Principal
* **Maria Eduarda** – Desenvolvedora de Funcionalidades (Feature Developer)
* **Mayara** – Revisor de Código e Analista de Qualidade

## Estrutura de Itens de Configuração (ICs)
* `main.py`: Ponto de entrada da aplicação e menu interativo.
* `tasks.py`: Regras de negócio e manipulação das tarefas.
* `storage.py`: Gerenciamento de persistência de dados.
* `tasks.json`: Arquivo local de armazenamento das tarefas.
* `Relatório de Gerenciamento de Configuração de Software.pdf`: Documentação oficial do projeto.
